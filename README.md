# 折叠森林 Forest Fold — 六边形策略 Demo

Unity 2022.3.62f1，Windows 版本。双击 `Builds/Windows-ShapeExpansion/ForestFold.exe`；分发需复制整个 Windows 文件夹。

## 从源码打开和构建

1. 安装 Unity 2022.3.62f1，通过 Unity Hub 打开此仓库根目录。
2. 打开 `Assets/Scenes/ForestFold.unity`，点击 Play 运行。
3. 菜单 `Forest Fold / Build Windows Demo` 构建 Windows 版；`Build macOS Demo` 构建 Intel + Apple Silicon 通用 Mac 版（需安装 Mac Build Support Mono）。构建前自动运行规则检查。
4. Mac 构建后可运行 `python PackageMac.py` 生成保留执行权限的 ZIP；使用其他构建目录时，通过 `--source` 和 `--output` 指定路径。

仓库包含 Assets（含 .meta）、Packages、ProjectSettings、构建脚本和设计说明。Unity 缓存、个人编辑器配置、日志及 Builds 打包产物不进入版本控制；下文的本机启动路径需先构建才会存在。

## 本局流程

1 章、3 张小地图、每图 8 波。初始 20 生命、18 金币、4×4 背包，有两件1星芽芽。每波先进行两次地块三选一，拖动放置，R 每次旋转60度。选完后可免费移动、互换和旋转已有地块；核心固定。允许调整过程中断路，开战前要求道路接口匹配、所有地块连通核心且至少保留一个外围入口。

地图使用真正的六边轴坐标、六向道路、六向寻路。直路、120度弯道及连接相邻两条边的60度急弯均无伙伴位，三岔3位、四岔4位。道路使用连续曲线，怪物沿同一曲线移动。四岔抽取权重降为3（直路30、普通弯道25、三岔35、急弯25），候选通常不重复，并优先保底三岔。槽位以金边深绿加号显示。怪物从外围开放口进入，沿最短道路到核心；普通漏怪扣1，攻城兽扣3。

每件伙伴分别提供与星级相同的出战数量，重复件累加：一件1星提供1只1星，一件2星提供2只2星，一件3星提供3只3星。同种混装1/2/3星共6只，各自保留星级、技能和属性，升星不覆盖其他物品；优先喜爱地形、其次中立、最后厌恶地形，无空位则待命。每波重新生成。

## 付费地图操作

选完本波两块后，点击地图地块，再使用左下按钮：

- 清除重建：5金币，重新三选一并放回高亮位置，确认替换才扣钱；取消不扣钱。可改变道路和生态，等级重置为1，然后可免费重排。
- 地块合成：8金币，消耗一个相邻同生态、同等级地块，选中地块升一级，上限3级。保留选中地块的道路；合成导致断路时可免费重排。
- 恢复布局：恢复到本次三选一结束或最近一次付费交易后的布局，不能返还已消费的地块或撤销扣费。

## 地形本身的作用

| 地形 | 基础效果 | 相邻联动 |
| --- | --- | --- |
| 草甸 | 敌人进入时承受2×等级荆棘直伤，每次进入只触发一次 | 邻林地时荆棘翻倍，双方增加15%+5%×各自等级的减速 |
| 林地 | 施加10%×等级直伤易伤，离开后保留2秒 | 邻草甸产生上述荆棘联动 |
| 水域 | 在地块内减速20%+5%×等级 | 邻沼泽再增加15%减速 |
| 沼泽 | 每秒2×等级毒伤，离开后持续2秒 | 邻水域再增加每秒2点毒伤 |

地图边界会标出“联动”，悬停标记显示双方具体增益与当前数值。减速敌人带蓝色脚环及百分比状态牌，中毒/易伤也标明，草甸入场伤害触发立体地刺与冲击环。悬停地块查看当前效果与伙伴偏好。升级提高地块效果，不会增加伙伴种类上限。

## 敌人预告与对策

本版强化波次成长：第2波起生命再乘1+0.18×(波数−1)+0.035×(波数−1)²；第8波约为旧版3.98倍。第4波开始每波额外增加2只，出怪间隔由0.72秒逐波缩短到0.405秒，第8波两只攻城兽。前两波统一使用新背包的入门难度，第1波降低血量作为开局适应波次。

规划和商店顶部预告下一波实际种类与数量，悬停查看对策，使用与刷怪相同的固定名单。

| 敌人 | 特点 | 推荐应对 |
| --- | --- | --- |
| 暗影 | 常规敌人 | 基础防线 |
| 疾行兽 | 1.7倍速度，较少生命 | 水域、青蛙减速 |
| 铁甲龟 | 直伤减半、血量较高、移动缓慢 | 沼泽和蘑菇毒伤 |

| 净化灵 | 毒伤和减速效果仅25% | 猫头鹰直接伤害 |

## 伙伴、射程与生态技能

| 伙伴 | 覆盖规则 | 喜爱地形的技能 | 厌恶地形 |
| --- | --- | --- | --- |
| 芽芽 | 圆形射程，半径4.1 | 草甸：三重叶弹 | 沼泽 |
| 猫头鹰 | 可跨地块射击，半径8.5 | 林地：穿透光束 | 沼泽 |
| 蘑菇 | 圆形射程，半径3.4 | 沼泽：持续4秒毒池 | 水域 |
| 青蛙 | 可跨地块射击，半径5.1 | 水域：扩散减速波 | 草甸 |

所有伙伴均按水平圆形射程索敌，不受地块边界限制。战斗时悬停任意伙伴可查看实际圆形覆盖区域。厌恶地形使伤害乘0.65、攻击间隔乘1.25，蘑菇额外失去毒性，青蛙失去减速。中立地形维持基础技能。

喜爱状态显示金绿光环、上升光点和“↑强化”；厌恶状态显示紫色断环、下沉箭头和“↓削弱”；正常状态无附加特效。

## 背包形状、相邻道具和合成

背包仍使用方格，地图使用六边形。

- 同种物品可以有不同形状。3格有I/L形，4格有方形、长条、L/T/S形；商店中部预览实际购买的形状。
- 选中伙伴或道具后可花3金币重掷形状，格数、种类、等级不变。先尝试原位，再寻找其他空位；无可容纳的新形状不扣钱。2格只有横竖朝向变化。
- 拖动整理：覆盖单个物品后，将该物品接到手上继续放置；覆盖两个物品或越过已解锁格子会拒绝，仍保留手持。Esc撤销整次连续交换。选中物品可点击“旋转90° $1”或按R旋转，费用1金币；原位放不下或旋转后形状相同不扣钱。手持旋转同样收费。战斗时锁定背包。
- 三件同种同级伙伴可直接三合一，不要求相邻。保留优先选中的那件形状，释放另外两件占格，等级上限3。如果三件还能拼成无空洞矩形，额外奖励3金币。
- 力量水晶：放入即生效，全体伤害每件+18%×等级。
- 风铃：仅强化边缘相邻的伙伴种类，每件+25%×等级攻速，斜角不算。碰到同种多件时同一个风铃只计一次。激活后显示金边。
- 重复毒伤取较强值，不无限叠加；减速取最强效果。

每波开放商店，4格商品，刷新2金币。第一波保证出售一只猫头鹰，让本地防线有机会升级为跨地块覆盖。背包扩展片随机上架，每件等概率提供1～4格（接近画布上限时限制为剩余格数），每格3金币。购买时会固定生成1～4格的连通形状及朝向（如长条、L形、方形），商店按实际形状展示。购买后整块跟随鼠标，移动到背包边缘松手放置，不能拆分或旋转。整块不能覆盖已有背包或超出画布，至少一格与已有背包边缘相连，斜角不算；初始4×4位于8×6画布中间，允许向四周扩展。手持扩容块期间不能继续采购或离开商店；Esc取消并退还购买费用，商品形状不变。完全无处放置的形状无法购买且不扣钱。买不起、放不下或扩容已满时不扣钱。第8波后直接结算。通关立即清空背包；下一关地图、金币、生命、背包容量、经验及buff均重置，回到两件1星芽芽、18金币、20生命、4×4背包。

## 局内升级与永久培养

击杀普通敌人得1经验、攻城兽得5经验。等级从1开始，升级所需经验为8、14、20……；升级暂停战斗，三选一，可叠加：全伙伴伤害+15%（含毒伤）、攻速+12%、射程+8%，或商店二级伙伴概率+20%（最高100%，满层后退出候选）。二级伙伴价格为一级的两倍，实际购买、部署、合成使用二级属性。升级经验与buff仅本关有效。

每通关一关获得3永久培养点。开局未铺地块或关卡结算时，可点顶部“伙伴培育”。四类伙伴分别培养，每级基础伤害+5%，上限5级，逐级消耗1/2/3/4/5点。永久培养与局内合成等级独立；培养点和等级由Unity PlayerPrefs本地保存，重新开局不会清除。自动测试使用隔离状态，不改玩家培养存档。

## 逐件升星技能

伙伴继续通过三件同种同星合成（无需相邻），保留一件占格。例如3件1星可部署3只；合成1件2星后部署2只2星，空出两件的背包位置。每件保留自己的星级，空槽不足的伙伴待命。

| 伙伴 | 1星 | 2星 | 3星 |
| --- | --- | --- | --- |
| 芽芽 | 单叶弹 | 双叶齐射 | 三叶齐射 |
| 猫头鹰 | 单体狙击 | 增加1次近邻弹射 | 增加2次近邻弹射 |
| 蘑菇 | 范围孢子 | 留下毒池 | 三簇毒池 |
| 青蛙 | 小范围水弹 | 扩散冲击波 | 双重冲击波 |

生态另行叠加：草甸使芽芽再多2片叶弹；林地为猫头鹰增加穿透；沼泽扩大蘑菇毒池，2星产生双毒池；水域扩大青蛙冲击波并增强减速，2/3星再增加一轮冲击波。厌恶地形继续削弱伤害与攻速，蘑菇在水域不产生毒池，青蛙在草甸失去减速。攻击数值仍按自身星级成长，背包和场上伙伴的悬停气泡可查看星级技能。

验证说明：星级技能有独立运行检查，1+2+3混装检查各星级实际数量。流程脚本第1图使用正常20生命；第2、3图提高测试核心血量以遍历所有流程，不能据此判断实际通关难度。
